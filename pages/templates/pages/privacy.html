Integritetspolicy

Så här behandlar vi personuppgifter när du bokar eller skickar ett meddelande.

Personuppgiftsansvarig

{{ site.site_name }} är personuppgiftsansvarig för de uppgifter du lämnar via webbplatsen. {% if site.email %} Kontakt: {{ site.email }}{% if site.phone %}, tel {{ site.phone }}{% endif %}. {% elif site.phone %} Kontakt: tel {{ site.phone }}. {% endif %}

Vilka uppgifter vi samlar in

  • Kontaktformulär: namn, e-post, eventuellt telefonnummer, ämne och meddelande.
  • Bokning: namn, e-post, telefonnummer, vald behandling och tid, samt hur du vill ha bekräftelse (e-post och/eller SMS).

Varför vi behandlar uppgifterna

Vi använder uppgifterna för att svara på ditt meddelande, genomföra bokningen och skicka bekräftelse. Rättslig grund är avtal (bokning) och berättigat intresse eller samtycke (kontaktförfrågan).

Hur länge vi sparar

Kontaktmeddelanden och bokningar sparas så länge de behövs för att hantera förfrågan och bokningen, och därefter enligt bokförings- och dokumentationskrav. Du kan be oss radera uppgifter som inte längre behövs.

Delning

Vi säljer inte dina uppgifter. Bekräftelser kan skickas via e-postleverantör och, om du valt SMS, via SMS-leverantör. Webbplatsen hostas hos vår driftleverantör.

Dina rättigheter

Du har rätt att begära registerutdrag, rättelse, radering och begränsning, samt att invända mot viss behandling. Kontakta oss via kontaktformuläret{% if site.email %} eller {{ site.email }}{% endif %}. Du kan också vända dig till Integritetsskyddsmyndigheten (IMY) (öppnas i ny flik).
