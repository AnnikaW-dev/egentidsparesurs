Integritetspolicy

Så här behandlar vi personuppgifter och cookies när du använder webbplatsen.

Personuppgiftsansvarig

{{ site.site_name }} är personuppgiftsansvarig för de uppgifter du lämnar via webbplatsen. {% if site.email %} Kontakt: {{ site.email }}{% if site.phone %}, tel {{ site.phone }}{% endif %}. {% elif site.phone %} Kontakt: tel {{ site.phone }}. {% endif %}

Vilka uppgifter vi samlar in

  • Kontaktformulär: namn, e-post, eventuellt telefonnummer, ämne och meddelande.
  • Bokning: namn, e-post, telefonnummer, vald behandling och tid.
  • Besöksstatistik: sidvisningar och unika besökare räknas anonymt med en hash som inte kan räknas tillbaka till din IP-adress. Råa IP-adresser sparas inte för detta.
  • Skräppostskydd: kontaktformuläret kan kontrolleras med Cloudflare Turnstile. Cloudflare kan då behandla tekniska uppgifter, till exempel IP-adress, för att avgöra att en människa skickar formuläret. Vi sparar inte den kontrollen.

Varför vi behandlar uppgifterna

Vi använder uppgifterna för att svara på ditt meddelande, genomföra bokningen och skicka bekräftelse med e-post. Rättslig grund är avtal (bokning) och berättigat intresse eller samtycke (kontaktförfrågan). Anonym besöksstatistik används för att förstå hur webbplatsen används (berättigat intresse).

Hur länge vi sparar

Kontaktmeddelanden och bokningar sparas så länge de behövs för att hantera förfrågan och bokningen, och därefter enligt bokförings- och dokumentationskrav. Du kan be oss radera uppgifter som inte längre behövs.

Delning

Vi säljer inte dina uppgifter. Bokningsbekräftelser skickas via e-postleverantör. Webbplatsen hostas hos vår driftleverantör. Skräppostkontrollen på kontaktformuläret görs av Cloudflare (Turnstile) när den är aktiverad.

Cookies

Webbplatsen använder bara cookies som behövs för att den ska fungera säkert: till exempel för att skydda formulär och för att du ska kunna vara inloggad i admin. Kontaktformulärets skräppostskydd (Cloudflare Turnstile) kan sätta en nödvändig cookie för den kontrollen. Vi använder inte cookies för statistik, reklam eller spårning, och vi visar därför ingen cookie-ruta. Om vi senare lägger till sådana tjänster uppdaterar vi den här texten och ber om samtycke först.
